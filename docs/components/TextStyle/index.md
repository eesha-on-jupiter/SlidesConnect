# Text Style

Styling for text that already lives in a shape, placeholder or table cell, the Slides counterpart of
DocsConnect's Text and Paragraph tabs. Every component takes Object ID(s) (from Create Shape, Styled
Text Box, Create Slide's placeholder outputs, or a table), every trait is a list, and each emits one
request per record. Styled Text / Styled Paragraph take every trait at once; the rest take exactly
one. Per-letter / per-word styling is in [Styled Text Box](../Text/StyledTextBox.md)'s Same Box mode.

| Component | Description |
|---|---|
| [Styled Text](UpdateTextStyle.md) | Styles the text already in shapes or cells: bold, italic, underline, strikethrough, size, font, colour, highlight, link, baseline, small caps. |
| [Styled Paragraph](UpdateParagraphStyle.md) | Styles paragraphs already in shapes or cells: alignment, line spacing, indents, space above/below, direction. |
| [Bullet List](BulletList.md) | Turns the paragraphs in shapes or cells into a bulleted or numbered list. |
| [Bold Text](BoldText.md) | Makes the text in one or more shapes bold (or un-bold). |
| [Italic Text](ItalicText.md) | Makes the text in one or more shapes italic. |
| [Underline Text](UnderlineText.md) | Underlines the text in one or more shapes. |
| [Strikethrough Text](StrikethroughText.md) | Strikes through the text in one or more shapes. |
| [Font Size Text](FontSizeText.md) | Sets the font size of the text in one or more shapes. |
| [Font Family Text](FontFamilyText.md) | Sets the font family of the text in one or more shapes. |
| [Text Color Text](TextColorText.md) | Sets the colour of the text in one or more shapes. |
| [Highlight Text](HighlightText.md) | Puts a highlight colour behind the text in one or more shapes. |
| [Link Text](LinkText.md) | Turns the text in one or more shapes into a hyperlink. |
| [Baseline Text](BaselineText.md) | Raises or lowers the text in one or more shapes (superscript / subscript). |
| [Aligned Text](AlignedText.md) | Sets the paragraph alignment of the text in one or more shapes. |
| [Line Spacing Text](LineSpacingText.md) | Sets the line spacing of the paragraphs in one or more shapes. |
| [Indent Text](IndentText.md) | Indents the paragraphs in one or more shapes. |
| [Space Above Text](SpaceAboveText.md) | Adds space above the paragraphs in one or more shapes. |
| [Space Below Text](SpaceBelowText.md) | Adds space below the paragraphs in one or more shapes. |
