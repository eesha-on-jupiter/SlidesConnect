# Shapes

| Component | Description |
|---|---|
| [Create Shape](CreateShape.md) | Builds createShape requests: position, size, rotation, optional fill and outline. |
| [Update Shape Style](UpdateShapeProperties.md) | Restyles a shape: fill, transparency, outline, shadow, text alignment, autofit, link. |
| [Shape Fill](ShapeFill.md) | Sets fill colour and/or transparency. |
| [Shape Outline](ShapeOutline.md) | Sets outline colour, weight and/or dash. |
| [Shape Shadow](ShapeShadow.md) | Adds or removes a drop shadow (colour, transparency, blur, offset). |
| [Shape Link](ShapeLink.md) | Hyperlinks the whole shape. |
| [Shape Text Fit](ShapeTextFit.md) | Vertical text alignment and autofit. |
| [Update Shape Transform](UpdateShapeTransform.md) | Builds requests to reposition, scale, or rotate a shape. |
| [Rhino Shape Export](RhinoShapeExport.md) | Converts Rhino rectangles into Slides position, size and rotation. |
