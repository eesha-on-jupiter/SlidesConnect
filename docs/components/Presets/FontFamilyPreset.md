# Font Family

Curated shortcut list of common font families for Styled Text / Font Family Text; not a closed list, any Google Fonts name can be typed directly.

A value-list (dropdown); wire its output into the matching string input. The strings are the Google
Slides API enum values, which differ from Google Docs' in places.

| Label | Value |
|---|---|
| Arial | `Arial` |
| Calibri | `Calibri` |
| Times New Roman | `Times New Roman` |
| Georgia | `Georgia` |
| Verdana | `Verdana` |
| Courier New | `Courier New` |
| Garamond | `Garamond` |
| Trebuchet MS | `Trebuchet MS` |
| Roboto | `Roboto` |
| Open Sans | `Open Sans` |
