# Border Position

Which borders of a table range Table Borders styles.

A value-list (dropdown) — wire its output into the matching string input. The strings are the Google
Slides API enum values, which differ from Google Docs' in places.

| Label | Value |
|---|---|
| All | `ALL` |
| Outer | `OUTER` |
| Inner | `INNER` |
| Inner Horizontal | `INNER_HORIZONTAL` |
| Inner Vertical | `INNER_VERTICAL` |
| Top | `TOP` |
| Bottom | `BOTTOM` |
| Left | `LEFT` |
| Right | `RIGHT` |
