# Text

| Component | Description |
|---|---|
| [Insert Text](InsertText.md) | Builds requests to insert text into a shape or placeholder. |
| [Replace All Text](ReplaceAllText.md) | Builds a find/replace request across the whole presentation. |
| [Styled Text Box](StyledTextBox.md) | Creates a text box, inserts the text and applies any combination of styles in one call — or, with Same Box, styles each letter/word of one box separately. |
